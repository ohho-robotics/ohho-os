# TypeScript SDK moved

The OhhO TypeScript SDK (`@ohho/schemas`, `@ohho/connect`, `@ohho/client`, and private `@ohho/mcp`) now lives in its own repository:

**https://github.com/ohho-robotics/ohho-sdk**

Use that repo for npm installs, builds, tests, and CI. This `ts/` folder is only a pointer so old links and docs stay valid.
